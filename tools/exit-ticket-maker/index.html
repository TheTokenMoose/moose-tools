Exit Ticket Maker

Build a ticket → project it live → or print student copies

How to use
  1. Pick a template (3-2-1, One question, Traffic light, Reflection, or Custom).
  2. Edit the title, prompts, and optional class / topic line.
  3. Live display — full-screen board for students to answer on whiteboards, sticky notes, or orally.
  4. Print — choose tickets per page, then use your browser Print dialog (Save as PDF works too).
  5. Nothing is uploaded. Optional saves stay in this browser only.
