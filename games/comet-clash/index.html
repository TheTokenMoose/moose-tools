How teachers run it
  1. Project this page. Split the class into teams.
  2. Read the question aloud (or let confident readers try).
  3. Teams discuss; teacher or a rotating “captain” taps the answer.
  4. Correct answers score points. Streaks unlock power-ups.
  5. Highest score at the end wins galactic bragging rights.
